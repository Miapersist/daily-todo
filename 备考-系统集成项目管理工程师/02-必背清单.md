# 02 · 必背清单（考场默写用）

> 用法：10/5 起每天早晚各默一遍，10/23 前做到闭卷能写全。

## 一、计算题 5 大类（案例必考，目标满分）

### 1. 挣值分析 EVM

| 量 | 公式 | 含义 |
|---|---|---|
| PV | 计划工作量 × 预算 | 计划该值多少 |
| EV | 已完成工作量 × 预算 | 实际干了值多少 |
| AC | 实际花费 | 实际花了多少 |
| CV | `EV − AC` | <0 超支 |
| SV | `EV − PV` | <0 落后 |
| CPI | `EV / AC` | <1 超支 |
| SPI | `EV / PV` | <1 落后 |
| BAC | — | 总预算 |
| EAC | `BAC / CPI`（典型）／`AC + (BAC − EV)`（非典型） | 完工估算 |
| ETC | `(BAC − EV) / CPI`（典型）／`BAC − EV`（非典型） | 完工尚需估算 |
| VAC | `BAC − EAC` | 完工偏差 |
| TCPI | `(BAC − EV) / (BAC − AC)` | 完工尚需绩效指数 |

### 2. 关键路径

- `ES / EF / LS / LF`
- 总浮动 `= LF − EF = LS − ES`
- 自由浮动 `= 紧后活动 ES 最小值 − 本活动 EF`
- **关键路径 = 工期最长、总时差为 0、决定最短完工时间**
- 压缩工期：**赶工**（加人加钱，成本↑）vs **快速跟进**（串行改并行，风险↑）

### 3. 三点估算 / 完工概率

- 期望 `= (O + 4M + P) / 6`
- 标准差 `σ = (P − O) / 6`
- 完工概率：查正态分布（±1σ≈68%，±2σ≈95%，±3σ≈99%）

### 4. 沟通渠道

- `n(n − 1) / 2`（n 含项目经理）

### 5. 决策树 EMV

- `EMV = Σ(概率 × 收益)`，选最大

> 补充：赶工压缩排序先算**每天赶工成本**，从便宜的开始压。

## 二、案例万能话术（改错题直接套）

### 找错句式

`XX 流程不规范` / `缺少 XX 过程` / `未进行 XX 评审` / `未走审批流程` / `沟通方式不当` / `风险管控缺失`

### 整改句式

`完善管理制度` / `规范项目流程` / `加强评审审批` / `做好书面留痕` / `加强监控复盘` / `提前识别风险`

### 通用万能句（不会写就抄）

**错误**：①缺少书面文档、无留痕记录；②流程不规范、缺少评审环节；③沟通不到位、信息不对称；④风险预判不足、无应急预案；⑤管控力度不足、监管缺失。

**整改**：①完善文档资料，做到书面留痕；②严格执行标准流程，增加评审环节；③建立沟通机制，定期汇报同步；④提前识别风险，制定应对预案；⑤加强人员管控，明确岗位职责。

### 计算题专用话术（挣值类）

- 问题描述：`CPI < 1 成本超支，SPI < 1 进度落后，项目整体绩效较差。`
- 改进：①更换高效率人员；②优化工作流程删减冗余；③严控成本支出；④赶工/快速跟进压缩工期；⑤加强质量管控减少返工。

### 十大管理 错误 → 整改 速查

| 领域 | 高频错误 | 标准整改 |
|---|---|---|
| 整体 | 无章程 / 无整体计划 / 口头变更 / 未评审 | 高层书面授权、制定管理计划、书面变更审批、评审共识 |
| 范围 | 需求收集不全 / 未评审 / 边界模糊 / **镀金** / 无核实 | 多方式调研、需求评审、编写范围说明书、严控范围 |
| 进度 | 估算乐观 / 计划不合理 / 监控不到位 / 关键路径失控 | 科学估算留缓冲、制定计划、比对基准、管控关键路径 |
| 成本 | 估算粗略 / 无基准 / 监控缺失 / 无应急储备 | 精细估算、制定成本基准、定期核算、预留储备 |
| 质量 | 无标准 / 检查不足 / 重开发轻测试 / 无审计 | 制定质量指标、加强过程检查、重视测试、定期审计 |
| 资源 | 职责不清 / 缺培训 / 无团建 / 冲突处理粗暴 | RACI 明责、岗前培训、团建、柔和方式处理冲突 |
| 沟通 | 无沟通计划 / 口头无留痕 / 方式错误 / 无反馈 | 编制沟通计划、重要事项书面化、选对方式、确认反馈 |
| 风险 | 识别不全 / 未分析 / 无预案 / 无登记册 | 多方识别、风险分析定级、应对策略、动态更新登记册 |
| 采购 | 未招投标 / 供应商资质松 / 条款模糊 / 口头合同 | 遵守招投标、审核资质、完善条款、必须书面合同 |
| 干系人 | 识别遗漏 / 未分析诉求 / 忽视弱势 / 未更新登记册 | 全程识别、权力利益方格差异化管理、动态维护 |

## 三、高频简答默写题

| # | 问题 | 标准答案（关键词） |
|---|---|---|
| Q1 | 项目章程作用 | 正式批准项目、任命项目经理、授予资源权限、明确高层级目标 |
| Q2 | **变更流程** | 书面申请 → 影响分析 → CCB 审批 → 执行 → 更新文档并通知干系人 |
| Q3 | 项目收尾工作 | 产品验收、文档归档、总结经验教训、释放资源、更新组织过程资产 |
| Q4 | 范围蔓延原因 | 需求定义不清、缺变更控制流程、客户频繁口头改需求、管控不足 |
| Q5 | WBS 分解原则 | 逐层分解、工作包最小化、责任到人、不重复不遗漏、便于估算管控 |
| Q6 | 工期延误原因 | 估算不准、资源不足、关键活动延误、风险预判不足、沟通不畅 |
| Q7 | 压缩工期方法 | 赶工（加人加钱）、快速跟进（串行改并行）、优化流程删冗余 |
| Q8 | 成本超支整改 | 严控支出、优化人员结构、提升效率、重评预算、减少返工 |
| Q9 | 质量审计目的 | 识别违规流程、总结优秀经验、优化过程规范、减少质量缺陷 |
| Q10 | 团队冲突解决原则 | 双赢优先、尽早处理、私下沟通、客观公正 |
| Q11 | 冲突方式优先级 | 合作 > 妥协 > 缓和 > 强迫 > 回避 |
| Q12 | 风险四大策略 | 规避、减轻、转移、接受 |
| Q13 | 风险登记册内容 | 风险描述、概率影响、责任人、应对措施、风险状态 |
| Q14 | 三类合同选型 | 固定总价（范围清晰，乙方风险大）、成本补偿（范围模糊，甲方风险大）、工料（短期临时） |
| Q15 | 质量成本四类 | 预防成本、评估成本、内部失败成本、外部失败成本 |
| Q16 | 配置管理活动 | 配置识别、配置控制、配置状态记录、配置审计 |
| Q17 | 可行性研究内容 | 技术、经济、社会、运行、法律 |
| Q18 | 需求调研方法 | 访谈、问卷调查、会议讨论、原型分析、现场观察 |
| Q19 | 项目失败常见原因 | 需求不明、变更混乱、资源不足、沟通不畅、风险预判不足 |
| Q20 | 干系人权力利益方格 | 高高→重点管理；高权低益→令其满意；低权高益→随时告知；低低→监控观察 |

## 四、易混辨析（选择题挖坑点）

- **审计审流程，检查查产品**
- **应急储备**：已知风险、在成本基准内、不需变更；**管理储备**：未知风险、在基准外、需审批
- **赶工**＝加人加钱（成本↑）；**快速跟进**＝串行改并行（风险↑）
- **邀请招标 ≥ 3 家**
- **鱼骨图 = 因果图 = 石川图**（找根因）；**帕累托图**（二八排序）
- **推式**（推送）/ **拉式**（自取）/ **交互式**（双向）
- 团队五阶段：形成 → **震荡（冲突最多）** → 规范 → 表现 → 解散
- 铁三角＝范围/进度/成本；**质量是核心目标，不是制约因素**
- 项目三属性：临时性、独特性、渐进明细（**重复性是运营**）
